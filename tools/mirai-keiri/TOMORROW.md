### ⑥ 請求書を あつめる　（10分）

会社ごとに 1まいずつ。できれば 10社分。

⚠️ **患者さんの名前が 書いてあるものは 持ち出さない。**
　　その場で 写真も とらない。

**そのとき、1つだけ 見てほしいことがあります。**

請求書のどこかに、こういう番号が 印字されています:

```
適格請求書発行事業者登録番号：T9310001000026
              （「T」＋ 数字13桁）
```

インボイス制度の番号で、ふつうは 金額の表の すぐ下か、
会社名のあたりに あります。

**集めた請求書 全部に この番号があるか** を見て、下に ✓ をつけてください。

| 会社名 | 番号があった？ |
|---|---|
| | あった / なかった |
| | あった / なかった |
| | あった / なかった |
| | あった / なかった |
| | あった / なかった |

→ ぜんぶ「あった」なら、**どの会社の請求書かを 機械が確実に見分けられます。**
　（この番号は ネットにつながなくても 本物かどうか判定できます）

→ 「なかった」会社がいたら、その会社は 別のやり方で 見分けます。
　 なかったこと自体は 問題ありません。メモするだけでOK。
